# Beginner Friendly Python Bank Management System

This is a beginner-friendly Bank Management System project built using Python.

The project is completely logic-based and runs in the terminal/console. It allows users to create and manage bank accounts while storing data permanently using a JSON file.

## Features

- Create a new bank account
- Deposit money
- Withdraw money
- Check account details
- Update account information
- Delete bank account
- Random account number generation
- Data storage using JSON file
- File handling for reading and writing data

## Technologies and Modules Used

This project uses the following Python modules:

- `json`
- `random`
- `string`
- `Path` from `pathlib`

## Files in Project

### `main.py`
Contains the complete Bank Management System logic and functionalities.

### `data.json`
Used for storing user account data permanently in JSON format.

## Concepts Used

- Python Classes and Objects
- Static Methods
- File Handling
- JSON Data Handling
- Lists and Dictionaries
- Random Data Generation
- Conditional Statements
- Loops

## How It Works

The program provides a menu-driven interface where users can choose different banking operations such as:

1. Create Account
2. Deposit Money
3. Withdraw Money
4. Check Account Details
5. Update Account Details
6. Delete Account

All account data is stored in `data.json` using file handling and JSON operations.

## How to Run the Project

Make sure Python is installed on your system.

Run the following command in terminal:

```bash
python main.py
```

## Sample Functionalities

- Generates random account numbers using letters, numbers, and symbols
- Stores account balance and user details
- Updates account data automatically in JSON file
- Validates PIN and account number before transactions
